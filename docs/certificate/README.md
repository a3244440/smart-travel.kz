# Сертификат на Умру VIP (бланк без ФИО)

- `sertifikat-umra-vip-blank.pdf` — готовый бланк A4 (альбомный): поля «Вручается» и «Пассажиры» пустые, их заполняют от руки.
- `cert.html` — исходник. Чтобы вписать имена или поменять дату, формат, пожелание, отредактируйте текст в нём и пересоберите PDF:
  `node docs/certificate/pdf.mjs "$PWD/docs/certificate"` → `out.pdf`.
- Шрифты: Forum, Manrope, Amiri (SIL OFL). Фото: assets/tours/umrah-vip.jpg.
