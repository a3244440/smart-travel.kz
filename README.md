# smart-travel.kz — платформа

Сайт для [@alina.smarttravel.kz](https://www.instagram.com/alina.smarttravel.kz/): Умра, Мекка, Медина и туры по миру, оформление визы в Саудовскую Аравию по фото паспорта.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная и каталог туров |
| `visa.html` | Виза: загрузка паспорта → автозаполнение анкеты → проверка → отправка заявки |
| `cabinet.html` | Статус заявки для клиента (по номеру заявки и телефону) |
| `about.html` | О нас: миссия, основатель, команда, как проходит поездка (цифры «5 лет», «1000+» — `stats` в `assets/config.js`) |
| `guides.html` | Гиды — «скоро появятся» |
| `admin.html` | Панель менеджера: все заявки, смена статуса, комментарий клиенту, выгрузка в CSV |

## Как редактировать

- **Номер WhatsApp, Instagram** — `assets/config.js`
- **Туры и цены** — `assets/tours.js` (`price: null` показывает «Цена по запросу»)
- **Статусы заявок** — `assets/store.js` (и список в `supabase/migrations`)
- **Подключение к Supabase** — `assets/config.js` (`supabaseUrl`, `supabaseKey`)
- **Цвета и шрифты** — `assets/style.css` (переменные в `:root`; светлая тема — в `:root`, тёмная — в блоках `dark`)
- **Тексты на языках** — `assets/i18n.js` (порядок в словаре: русский, казахский, английский, арабский); туры — `assets/tours.js`

## Курс валют и аят дня

- **Курс валют** в верхней полосе — курс продажи обменного пункта MiG (mig.kz). База Supabase сама забирает его каждые 30 минут (`pg_cron` + функция `refresh_rates`), сайт читает готовую таблицу `rates`.
- **Аят дня** на главной меняется каждый день (по времени Казахстана). 20 аятов о Хадже, Умре, Каабе, дуа и терпении лежат в таблице `ayat`; тексты загружены из api.alquran.cloud: арабский оригинал, перевод Кулиева (рус.), Sahih International (англ.), Халифы Алтая (каз.). Скрыть аят — `update ayat set active = false where ref = '2:201'`.

## Языки и тема

- Сайт на русском, казахском, английском и арабском (арабский — справа налево). Язык выбирается в шапке и запоминается; при первом заходе берётся язык браузера. Ссылка на конкретный язык: `?lang=kk`, `?lang=en`, `?lang=ar`.
- Панель менеджера всегда на русском. Текст заявки для менеджера (WhatsApp, CSV) тоже всегда на русском, на каком бы языке ни заполнял клиент.
- Тема по умолчанию — как в настройках устройства; кнопка ☾/☀ в шапке переключает и запоминает выбор.

## Распознавание паспорта

Работает прямо в браузере: [Tesseract.js](https://github.com/naptha/tesseract.js) читает машиночитаемую строку (MRZ) внизу паспорта и заполняет ФИО, номер, гражданство, пол, даты рождения и окончания, ИИН. Контрольные цифры MRZ проверяются автоматически. Место рождения, дату выдачи и орган выдачи клиент вводит сам.

Фото паспорта никуда не отправляется и не сохраняется.

## База данных (Supabase)

Проект Supabase `smart-travel.kz`, схема — `supabase/migrations/`.

- Клиент **не видит таблицу**: он только отправляет заявку (`submit_application`) и узнаёт статус по номеру заявки и телефону (`find_application`, отдаёт лишь имя, дату въезда, статус и комментарий).
- `admin.html` открывается после входа по email и паролю (Supabase Auth). Заявки видят и меняют только пользователи из таблицы `managers`.
- История статусов записывается в базе автоматически при смене статуса.

**Добавить менеджера:** Supabase → Authentication → Users → Add user (email + пароль, Auto Confirm), затем в SQL Editor:

```sql
insert into public.managers (user_id) select id from auth.users where email = 'manager@example.com';
```

**Закрыть регистрацию:** Authentication → Sign In / Providers → выключить «Allow new users to sign up».
