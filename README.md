# Alina Smart Travel — платформа

Сайт для [@alina.smarttravel.kz](https://www.instagram.com/alina.smarttravel.kz/): Умра, Мекка, Медина и туры по миру, оформление визы в Саудовскую Аравию по фото паспорта.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная и каталог туров |
| `visa.html` | Виза: загрузка паспорта → автозаполнение анкеты → проверка → отправка заявки |
| `cabinet.html` | Статус заявки для клиента (по номеру заявки и телефону) |
| `admin.html` | Панель менеджера: все заявки, смена статуса, комментарий клиенту, выгрузка в CSV |

## Как редактировать

- **Номер WhatsApp, Instagram, город** — `assets/config.js`
- **Туры и цены** — `assets/tours.js` (`price: null` показывает «Цена по запросу»)
- **Статусы заявок** — `assets/store.js`
- **Цвета и шрифты** — `assets/style.css` (переменные в `:root`)

## Распознавание паспорта

Работает прямо в браузере: [Tesseract.js](https://github.com/naptha/tesseract.js) читает машиночитаемую строку (MRZ) внизу паспорта и заполняет ФИО, номер, гражданство, пол, даты рождения и окончания, ИИН. Контрольные цифры MRZ проверяются автоматически. Место рождения, дату выдачи и орган выдачи клиент вводит сам.

Фото паспорта никуда не отправляется и не сохраняется.

## Ограничения прототипа — что нужно до запуска для клиентов

1. **Заявки хранятся в браузере (localStorage).** Панель менеджера видит только заявки, отправленные с того же устройства. Для реальной работы нужна база данных — проще всего [Supabase](https://supabase.com): заменить функции в `assets/store.js`, остальной код не меняется.
2. **Панель менеджера не защищена паролем.** Вход нужно сделать через ту же базу (Supabase Auth).
3. **Персональные данные.** По закону РК «О персональных данных и их защите» нужны согласие клиента на обработку (чекбокс на странице визы) и хранение данных граждан РК на серверах в Казахстане.
4. **Точное распознавание всех полей** (включая дату выдачи и место рождения) — через серверный запрос к Claude API (vision).
