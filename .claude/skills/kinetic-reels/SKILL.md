# Кинетические рилсы smart-travel.kz

Инструменты: `tools/kinetic/` (движок, рендер, звук, демо). Пример — `tools/kinetic/umrah-demo.html` + `umrah-demo.script.json`.

## Стиль (разобран по референсу)
- **Ритм**: новая надпись или элемент каждые 0,3–0,8 с, строго на начало фразы голоса. Пустых пауз нет.
- **Типографика**: смесь 3 шрифтов в одной фразе — узкий жирный капс (Oswald 700) для ключевого слова, рукописный (Marck Script) для эмоционального слова («Почему», «в Мекку»), маленький разреженный капс (Montserrat 600, letter-spacing .18em) для связок («называют», «всего»).
- **Появления** (пресеты движка): `zoom` (влетает из крупного с размытием), `pop` (пружина), `rise`/`drop`, `left`/`right` (резкий выезд), `track` (буквы съезжаются), `mask` (поднимается из-под линии), `slam` + счётчик (большая цифра с ударом), `glass` (стеклянная плашка), печать по буквам (`type: true`).
- **Камера**: всегда дрейфует (масштаб 1→1.07 за сцену), в списках следует за активным пунктом.
- **Переходы сцен**: `zoom` (пролёт сквозь), `up`, `left` (свайп), `circle` (круговое открытие), чередуются тёмная/светлая сцены.
- **Декор**: пузырьки, светящаяся арка-контур, силуэт мечети, полумесяц, фото в круге/арке с золотой обводкой, курсор с кликом, зелёные галочки, плёночное зерно и виньетка.
- **Цвета бренда**: тёмно-синий `#101A3A`, золото `#D4AF6A`/`#B8893A`, слоновая кость `#F6F0E4`. Логотип не искажать; на тёмном фоне — слой `logo-ink.png` белым + `logo-gold.png`.

## Звук (синхронизация автоматическая)
Каждое появление пишет метку в `window.CUES`; `sound.py` ставит звук ровно туда:
вжух на смену сцены (пик точно на склейке), «поп» на появление, «тик» на подъём текста, свист на `track`, клавиши при печати, двойной щелчок мыши у курсора, лёгкий «дзынь» на логотип/полумесяц, низкий удар на большую цифру.
Музыка — тихий пэд + мягкий бит 100 BPM, приглушается под голосом. Голос главный, но эффекты должны быть отчётливо слышны (≈3 дБ ниже голоса) — тихие эффекты пользователь не замечает. Итоговая громкость −14 LUFS.
Пользователь не любит: колокольчики, флейту, эхо/реверберацию — не добавлять.

## Как сделать новый ролик
1. Сценарий `*.script.json`: предложения → фразы `{id, say}`. В `say` — текст для синтеза; ударения чинить написанием (удвоенная гласная: «ихраам», «тавааф», «Сафаа»; «У́мру» с акутом работает только для первого слога). Проверка: `echo текст | piper ... --debug` показывает фонемы.
2. Голос: `PIPER=... PIPER_VOICE=... python3 tools/kinetic/voice.py сценарий.json OUT` → `voice.wav` + `timing.json` (время каждой фразы).
   Piper и голос ru «irinia» качаются с GitHub-релизов rhasspy/piper (`2023.11.14-2/piper_linux_x86_64.tar.gz`, `v0.0.2/voice-ru-irinia-medium.tar.gz`).
   Свой голос (ElevenLabs): положить `voice.wav` и вручную написать `timing.json` с теми же id.
3. Сцены: копия `umrah-demo.html`; `K.Scene(имя, начало, конец, {theme, enter, cam})`, элементы `sc.add(html, {x, y, at: ph("id") + сдвиг, anim})`. Факты проверять по сайту (`assets/i18n.js`, `assets/tours.js`).
4. Превью: `node tools/kinetic/render.mjs сцена.html OUT snap 1.5 4 8` → проверить кадры глазами (переполнение по ширине, читаемость).
5. Кадры: `node tools/kinetic/render.mjs сцена.html OUT` → `OUT/frames`, `OUT/cues.json`.
6. Звук: `python3 tools/kinetic/sound.py OUT <длительность>` → `OUT/mix.wav`.
7. Громкость под Instagram: `ffmpeg -i OUT/mix.wav -af loudnorm=I=-14:TP=-1:LRA=11 OUT/mix-loud.wav`.
8. Сборка: `ffmpeg -framerate 30 -i OUT/frames/%04d.jpg -i OUT/mix-loud.wav -c:v libx264 -crf 20 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest -movflags +faststart out.mp4`.
Файл больше 30 МБ не отправится пользователю — пережать (crf 22–24).
