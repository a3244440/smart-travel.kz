# Kinetic — ролики в стиле «кинетическая типографика»

Движок для вертикальных Reels: анимация текста под голос + автоматические звуки на каждое появление.
Подробная инструкция и правила стиля: `.claude/skills/kinetic-reels/SKILL.md`.

- `engine.js` — сцены, пресеты появлений, переходы, камера, звуковые метки
- `voice.py` — синтез голоса по сценарию и тайминг фраз
- `render.mjs` — покадровый рендер (Playwright) и экспорт меток
- `sound.py` — эффекты, музыка, сведение с голосом
- `umrah-demo.*` — пример: «Почему Умру называют малым Хаджем»
- `fonts/` — Oswald, Marck Script, Montserrat (SIL OFL 1.1)
